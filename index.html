အလုပ်လုပ်ပုံ (အဆင့် ၄ ဆင့်)

  1. 1

    အကောင့်ဖွင့်ပါ / ဝင်ပါ

    Register တွင် ဖုန်းနံပါတ်နှင့် စကားဝှက် ဖြည့်ပြီး အကောင့်ဖွင့်နိုင်သည်။ အသစ်ဖွင့်လျှင် 25 Coins + 15 mins အခမဲ့ ရရှိသည်။

  2. 2

    ဖိုင် သို့မဟုတ် စာသား ထည့်ပါ

    "ဖိုင်" tab တွင် PDF/Word/TXT တင်ပါ။ "စာသား" tab တွင် တိုက်ရိုက် ရိုက်ထည့်နိုင်သည်။

  3. 3

    ဘာသာပြန်စတိုင် ရွေးပြီး "ဘာသာပြန်မည်" ကို နှိပ်ပါ

    ရုံးသုံး / စကားပြေ / စာပေ — သုံးမျိုးမှ ရွေးနိုင်သည်။ AI မှ ဘာသာပြန်ပေးသည်။

  4. 4

    ရလဒ် ကြည့် / Download

    TXT/PDF/Word/Print ဖြင့် ထုတ်ယူနိုင်သည်။ မှတ်တမ်းများကို ပြန်ကြည့်နိုင်သည်။

Coin နှင့် အသုံးပြုချိန်

• 10 Coins = 1 နာရီ အသုံးပြုချိန် လဲလှယ်နိုင်သည်

• Coin ကို KPay / WavePay / USDT ဖြင့် ဝယ်ယူနိုင်သည်

• Admin မှ Coin ထည့်ပေးပြီးနောက် အသုံးပြုနိုင်သည်

• Coin ကို အခြား User များထံ လွှဲပြောင်းနိုင်သည်

အသုံးဝင်သော အကြံပြုချက်များ

  • Scan ဖတ်ထားသော PDF များတွင် စာသား မတွေ့နိုင်ပါ — text-based PDF ကို သုံးပါ။
  • စာမျက်နှာ ၅ ခုထက်ပိုသော ဖိုင်များကို Chunk ခွဲပြီး အပိုင်းလိုက် ဘာသာပြန်နိုင်သည်။
  • Word တွင် မြန်မာစာ မှန်ကန်စွာ မြင်ရန် Padauk font ကို install ထားပါ။
  • PDF သည် font ကို embed လုပ်ထားသောကြောင့် မည်သည့်စက်တွင်မဆို မှန်ကန်စွာ မြင်ရသည်။

ကိုယ်ရေးကာကွယ်မှု

သင့်၏ ဖိုင်များနှင့် စာသားများကို SarPay server တွင် မသိမ်းဆည်းပါ။ ဘာသာပြန်ရလဒ်များကို Firebase တွင် သင့်အကောင့်အောက်၌သာ သိမ်းထားပြီး သင့်မှ ဖျက်နိုင်သည်။
